## Stitch Screen Element Inventory

> Complete element list extracted from Stitch HTML. This is the source of truth for what each screen should contain.

### Dashboard
- **Hero Net Worth card**: Large "Total Net Worth" value, with Assets and Liabilities totals below, and a 12-month mini line chart (always shows last 12 months, ignores global time range)
- **Spending Concentration section**: 4 category rows with icons (Housing, Food & Dining, Transport, Lifestyle) + amounts + Total Outflow value + "View All" link
- **Monthly Cash Flow section**: "+24% surplus" comparison label, 4 metric cards (Net Liquidity, Total Income, Fixed Expenses, Invested), plus "Income - Spending - Investments Trend" multi-line chart
- **Recent Transactions panel** (right side): List of recent transactions with merchant, date, amount
- ~~New Home Savings goal card~~ — SKIPPED (savings goals out of scope)
- ~~AI Insight card~~ — SKIPPED (V2 scope)

### Income Overview
- **Hero card**: "Total Income" (NOT "Projected Income"), value based on selected time range, "+/- X% vs previous period" (rolling comparison), "XX Diversified Streams" count
- ~~Target Goal~~ — SKIPPED (savings goals out of scope)
- **Income Source cards**: 4 individual styled cards, each showing: source name, amount, description, badge (MONTHLY / VARIABLE / PASSIVE / FIXED — derived from category)
- **Historical Trajectory chart**: Bar chart with Linear / Cumulative toggle
- **Recent Credits section**: Renamed from "Transactions", green checkmark icons per entry, "+$X" styled amounts

### Spending & Transactions
- **Header metrics row**: 3 cards — Total Spending (with +/- % from previous period), Monthly Average (NOT daily average), Top Category (name + % of total)
- **Category Breakdown**: Category list with icons per category (home, shopping_basket, restaurant, subscriptions, etc.) + progress bars + amounts
- **Recent Transactions**: Table format with columns: Merchant/Payee, Category, Date, Amount
- ~~Savings Forecast~~ — SKIPPED (savings goals out of scope)

### Investments Portfolio
- **Portfolio Value hero**: Total value with +/- $ change and % from period start
- **Performance History chart**: Always last 12 months, smooth line, monthly markers (independent of global time range)
- **Allocation donut**: Keep existing (already matches Stitch)
- **Holdings table**: Ticker, Name, Price (last refresh), Shares, Value, Allocation %
- ~~Portfolio Health / Optimizer~~ — SKIPPED (V2 scope)
- ~~Portfolio Insights~~ — SKIPPED (V2 scope)
- ~~Recent Activity~~ — SKIPPED

### Net Worth
- **Hero value**: Net Worth with +/- % change vs rolling previous period
- **Equity Trajectory chart**: Keep existing line chart
- **Assets section**: Prominent total value + icon-grouped breakdown by type (Checking, Savings, Investments, Crypto) with individual accounts listed
- **Liabilities section**: Prominent total value + icon-grouped breakdown by type (Credit Cards, Loans) with individual accounts listed
- ~~Quarterly Insight card~~ — SKIPPED (V2 scope)

### Accounts Management
- ~~Total Aggregated Balance hero~~ — SKIPPED (user decision)
- **Sync Status panel**: Active API connections count, Manual items count, Last Update timestamp, Refresh All button
- **Connected Institutions**: Starts at top of page (no hero above). Tabs: ALL / CASH / DEBT. Card-style layout per institution showing name, balance, last synced, trend
- ~~Smart Insights~~ — SKIPPED (V2 scope)
- ~~Security badge~~ — SKIPPED (not needed for personal app)
