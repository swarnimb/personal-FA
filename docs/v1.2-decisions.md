- **Kept:** "Monthly Average" metric (builder override — task spec said "Daily Average" but builder requested keeping Monthly)

### Dashboard MonthlyCashFlow rewrite (Stitch alignment fix)
- **Problem:** Original implementation showed 4 metric cards in a row + multi-line trend chart (Income/Spending/Investments as 3 separate lines). Stitch shows a different structure.
- **Stitch structure (verified via Puppeteer screenshot):**
  1. Header: "Monthly Cash Flow" title + surplus sentence on left, Net Liquidity large value on right
  2. Horizontal stacked bar: single `h-4` rounded bar with 3 colored segments (green=income, red=expenses, blue=investments) showing proportional breakdown
  3. Three metric cards: Total Income (green label, ArrowUpRight icon), Fixed Expenses (red label, Receipt icon), Invested (blue label, LineChart icon) — each card has a large faded icon on the right
  4. Single area chart: green monotone line with gradient fill — shows income trend only (not 3 separate lines)
- **Changed:** Rewrote `MonthlyCashFlow.tsx` to match Stitch exactly. Net Liquidity moved from metric card to header. Added stacked bar. Reduced trend chart from 3-line to single-area. Added lucide-react icons (ArrowUpRight, Receipt, LineChart) to metric cards.
- **Removed:** YAxis from trend chart (Stitch has no Y axis labels). Legend removed. LineChart → AreaChart.
